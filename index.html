About the Project

Android Security Scanner is a mobile application project focused on Android application analysis and document security inspection. It combines Android development, file processing and security-oriented analysis in one application.


The application was built, digitally signed and tested on a physical Android phone and an Android emulator.

Technologies Used

Tools and libraries used in the project.
